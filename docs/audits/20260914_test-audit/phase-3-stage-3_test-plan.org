* 1. Overview & Architectural Objectives

** Scope & Purpose
In accordance with =docs/phase-3_meta-plan.org= (§5), Stage 3 delivers two critical domain subsystems:
1. *Two-Phase LaTeX Math Tokenization*: Shields inline and display mathematical notation from premature prose Greek entity expansion, delivering pristine ASCII LaTeX syntax directly to KaTeX.
2. *Tripartite Headless AST Foundation*: Establishes pure, headless AST engines for:
   - Org-mode AST (=src/features/ast/org/=) with fine-grained math shielding.
   - CommonMark + GitHub Flavored Markdown (GFM) AST (=src/features/ast/markdown/=) with section hierarchies, callouts, and pipe tables.
   - Canonical JSON AST Intermediate Representation (IR) (=src/features/ast/json/=) providing structured turn modeling.

This document defines the forward-readiness test plan, test case matrix, fixture specifications, and verification gates for Stage 3 development.

* 4. Subsystem Verification Matrices

** 4.1 Two-Phase Math Tokenization Test Matrix

#+BEGIN_SRC text
Prose Input ───────► Phase 1: Delimit Math ───────► Phase 2: Entity Expansion ───────► Pure AST
                      (Tokens Shielded)               (Only Prose Modified)
#+END_SRC

| Test Case | Input Syntax | Phase 1 Tokenization | Phase 2 Expansion | Invariant / Expected AST Node |
|---+---+---+---+---|
| Inline Dollar Math | ~$E = mc^2$~ | ~MathInlineNode~ | Untouched | Formula delivered verbatim to KaTeX |
| Inline Paren Math | ~\( \alpha + \beta \)~ | ~MathInlineNode~ | Untouched | ~alpha~ and ~beta~ remain ASCII LaTeX commands |
| Display Double Dollar | ~$$ \int_0^\infty e^{-x} dx $$~ | ~MathDisplayNode~ | Untouched | Verbatim ASCII math formula preserved |
| Display Equation Env | ~\begin{equation}\lambda = \frac{h}{p}\end{equation}~ | ~MathDisplayNode~ | Untouched | ~\lambda~ remains ASCII command |
| Non-Math Prose Entities | ~Values: \alpha and \beta~ | ~TextRunNode~ | ~\alpha~ expanded | Prose expands to unicode or entity target |
| Mixed Math and Prose | ~Let \alpha be angle: $\cos(\alpha) = 1$~ | Math shielded; prose exposed | Prose expands; math untouched | Inside MathInlineNode, ~\alpha~ is verbatim |

** 4.2 CommonMark & GFM AST Test Matrix

| Component | Target Syntax | Verified Invariants |
|---+---+---|
| *ATX Headings* | ~# H1~, ~## H2~, ~### H3~ | Produces =HeadingNode= with correct depth (1-6) and auto-generated slug ID |
| *Section Nesting* | Hierarchical headings | Lower-rank headings (=H2=) are nested inside the body of preceding =H1= |
| *GitHub Alerts* | ~> [!NOTE]~, ~> [!TIP]~, ~> [!IMPORTANT]~, ~> [!WARNING]~, ~> [!CAUTION]~ | Produces =AlertNode= with designated variant, default localized title, and child body |
| *Pipe Tables* | ~| Header |~, ~| :--- | :---: | ---: |~ | Produces =TableNode=, =TableRowNode=, =TableCellNode= with correct text alignments |
| *Task Lists* | ~- [ ] Todo~, ~- [x] Done~ | Produces =TaskItemNode= with boolean =checked= property |
| *Code Fences* | ~```python~, ~~~~yaml~ | Produces =CodeBlockNode= capturing language tag and unescaped code body |

** 4.3 JSON AST & Intermediate Representation (IR) Test Matrix

| Component | Target Syntax | Verified Invariants |
|---+---+---|
| *JSON AST Parser* | Arbitrary JSON string | Produces =JsonDocumentNode= holding =JsonObjectNode=, =JsonArrayNode=, =JsonPrimitiveNode= |
| *Roundtrip Integrity* | Complex JSON payload | Serializing AST back to JSON produces identical object graph |
| *Turn to JSON IR* | Conversational Turn | Maps turn ID, speaker ("user" / "assistant"), timestamp, and content segments into =JsonTurnIr= |
| *JSON IR to Turn* | Canonical JSON IR | Reconstructs =ConversationTurnNode= without data loss |

* 5. Hermetic Test Fixture Requirements

1. *Zero Global Leakage*: Pure unit tests must execute in pure memory without instantiating global DOM shims.
2. *Deterministic Fixture Files*:
   - Complex test inputs exceeding 3 lines must reside in =tests/fixtures/data/math/= and =tests/fixtures/data/markdown/=.
   - Tests read fixtures synchronously via =tests/fixtures/fixture_loader.ts=.
3. *Single-Assertion Discipline*: Each test case must contain exactly one logical assertion (=assertEquals=, =assertStringIncludes=, =assertMatch=).
