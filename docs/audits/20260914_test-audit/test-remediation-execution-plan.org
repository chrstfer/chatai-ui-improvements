* Query & Inspection Infrastructure (=deno task audit:tests:query=)

To eliminate manual searching and minimize token expenditure during execution, the TypeScript query utility is registered and active:

#+BEGIN_SRC bash
deno task audit:tests:query [options]
#+END_SRC

** Primary Capabilities & Filters
- *-t, --issue <type>*: Filter by specific issue (=colon= / =missing-colon=, =missing-comp=, =multi-assert= / =aaa=, =zero-assert=, =category=, =quarantine=, or =all=).
- *-c, --cat <category>*: Filter by test category (=unit=, =integration=, =e2e=, =bench=).
- *-d, --dir <subdir>*: Filter by directory substring (e.g. =languages/org=, =features/chats=).
- *-f, --file-filter <str>*: Filter by file path or name.
- *-s, --suggest*: Automatically generate drop-in replacement names using the canonical component registry.
- *--format <compact|summary|remediation|json>*:
  - =compact= (default): Minimal output tokens (one line per test: line, issue tag, current name, and suggested replacement).
  - =summary=: Aggregated file-by-file count matrix.
  - =remediation=: Detailed punchlist with line ranges, names, suggestions, and issue descriptions.

** Query Recipe Examples for Execution Batches
#+BEGIN_SRC bash
# 1. Summary of all non-compliant tests by file
deno task audit:tests:query --format summary

# 2. Targeted punchlist for multi-assertion tests
deno task audit:tests:query -t multi-assert --format remediation

# 3. Compact suggestions for missing component prefixes in Org parser tests
deno task audit:tests:query -d languages/org -t missing-comp -s

# 4. Filter for specific file before refactoring
deno task audit:tests:query -f build_test.ts -s
#+END_SRC
