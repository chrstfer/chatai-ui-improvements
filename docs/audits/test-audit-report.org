* Executive Summary
Following the guidelines established in =docs/test-design.org=, =AGENTS.md=, and the =test_audit_plan.md= blueprint, a complete architectural overhaul ("Sort, Clean, Measure") of the automated test suite was executed on branch =phase-3_test-rework=.

Prior to this rework, the test suite suffered from architectural drift: compound test cases packing up to five distinct assertions into a single =Deno.test= block, bespoke DOM shimming scattered across test files, mixed test tier categories lacking standardized filtering, un-quarantined technical debt in site adapters, and absence of standardized Preact component testing utilities.

All 489 tests across the repository now strictly comply with the following invariants:
1. *Arrange-Act-Assert (AAA) Discipline*: Exactly one logical assertion per test case.
2. *Strict Categorical Prefixes*: Every test is classified with an explicit category prefix (=unit: =, =integration: =, =e2e: =), enabling selective execution via dedicated Deno tasks.
3. *Single DOM Shim Source of Truth*: All synthetic DOM shimming, selector polyfills, MutationObserver mocking, and event bubbling reside exclusively in =tests/fixtures/dom_fixture.ts=. Bespoke DOM mocks have been completely eradicated.
4. *Standardized Preact Component Testing*: All UI component tests utilize =@testing-library/preact= coupled with =setupTestDom= and hermetic cleanup lifecycle hooks.
5. *Zero Modifications to =src/=* Codebase: Test isolation, DOM polyfills, and event simulations were implemented entirely within =tests/=, respecting the technical debt quarantine directive.
6. *Reusable Firefox DevTools MCP Scripts*: Evaluation scripts for E2E validation of Duck.ai and Gemini site adapters are formalized under =tests/ff-devtools_e2e-tests/scripts/=.

* Key Structural Reworks

** 1. Centralization of DOM Shims in =tests/fixtures/dom_fixture.ts=
Previously, multiple test files independently shimmed =document.createElement=, =attachShadow=, =style= property maps, and =MutationObserver=. All synthetic browser APIs now originate exclusively from =setupTestDom()= in =tests/fixtures/dom_fixture.ts=:
- *:has() Query Polyfill*: Intercepts and manually resolves =:has(...)= pseudo-classes across =querySelector= and =querySelectorAll=.
- *Global Scope Shims*: Safely exposes =HTMLElement=, =Element=, =ShadowRoot=, =window=, and =Node= on =globalThis= during test execution, fully restoring originals in =cleanup()=.
- *Ancestor Event Bubbling*: =triggerClick= traverses =curr.parentNode=, dispatching synthetic =click= and =change= events while preserving =e.target= and respecting =e.stopPropagation()= (=cancelBubble=).
- *MockMutationObserver*: Centralized mock tracking instances, target nodes, and mutation callbacks with =trigger()= simulation.

** 2. AAA Discipline & Single Assertion Rule
Every test file was refactored from compound verification blocks to strict single-assertion units. For instance:
- =tests/views/codeblock/codeblock_view_test.tsx=: Decomposed from 7 monolithic multi-assertion tests into 29 atomic tests.
- =tests/features/chats/duckai/injector_test.tsx=: Decomposed from 3 compound tests into 19 isolated tests verifying element insertion, class assignments, dataset properties, shadow root attachments, duplicate injection guards, format bypasses, theme toggles, and teardown restoration.
- =tests/views/settings/floating_hud_test.tsx=: Decomposed into 18 discrete tests covering UI labels, preset buttons, bilateral boundary clamping, state toggles, and mount container unmounting.
- =tests/build/build_test.ts=: Decomposed into 14 atomic assertions using a memoized dev build runner to avoid repeated 1.5s compiler invocations.

** 3. Preact Testing Library Integration
Tests for =InlineImageView=, =LatexMathView=, =CodeBlockHeader=, =InSituCodeBlockContainer=, =FloatingHud=, and Org mode views were standardized on =@testing-library/preact=. This ensures consistent component lifecycles, hook evaluation (=useEffect= / =useLayoutEffect=), and clean unmounting.

** 4. Lint and Code Quality Compliance
Ran =deno lint tests/= across all 43 test modules, eliminating all unused variables, dangling async functions (=require-await=), and unnecessary type casts. The test suite passes =deno lint= with zero warnings or errors.

The test suite overhaul is complete. Branch =phase-3_test-rework= establishes a rock-solid, hermetic, and fast verification foundation. The test suite is fully decoupled from production implementation details while rigorously enforcing all architectural contracts.
