* src/
:PROPERTIES:
:PATH: src/
:PURPOSE: Root source directory for the Gemini Org-Mode UI Improver extension
:FILE_TYPES: .ts, .tsx, .css
:STATUS: Active
:END:

Root directory containing the extension's content scripts, reactive state contexts, host DOM extractors, multi-language parsers, styling architectures, and Preact UI components. The codebase adheres strictly to a declarative Preact-first architecture, single Preact root per mount boundary, deep module interfaces, and the Three-Layer Style Architecture.

*Root Entry Points*:
- ~constants.ts~ :: Canonical DOM selectors (~SELECTOR_ROOT~, ~SELECTOR_CODE_CONTAINER~, ~SELECTOR_DECORATION~, ~SELECTOR_LANG_SPAN~, ~SELECTOR_ACTIONS~) aligned with Gemini's host Angular elements.
- ~content.ts~ :: Main WebExtension content script entry point. Bootstraps ~SettingsStore~, mounts the single Preact ~ExtensionRoot~, activates ~DomObserver~, binds global shortcut keys (Alt+W, Alt+O, Alt+F), and configures dev-only inspection bridges.

** context/
:PROPERTIES:
:PATH: src/context/
:PURPOSE: Shared Preact Context providers, reactive state singletons, and AST caching
:FILE_TYPES: .tsx
:PRIMARY_SEAM: Preact Context API
:KEY_DEPENDENCIES: preact, preact/hooks, src/languages/org/types/ast.ts, src/ui/folding.ts
:STATUS: Active
:END:

Provides reactive application state across the extension's component tree. Maintains persistent AST caching and batch coordination across virtual DOM scroll lifecycles without requiring external global state libraries.

*Files & Responsibilities*:
- *~BlockStoreContext.tsx~*:
  - *~BlockStore~*: Central singleton store managing runtime block/turn registrations and AST caching.
  - *Fingerprint Engine*: $O(1)$ locally obvious content hashing (~computeContentFingerprint~) using 32-bit FNV-1a over language, length, prefix, and suffix to avoid full string traversal.
  - *AST Cache*: Retains parsed Org ASTs and fold states across virtual-scroll DOM unmount cycles, enabling instant re-hydration.
  - *Batch Coordination*: Coordinates global actions such as cycling outline fold states and cycling render modes across all registered blocks and turns.
  - *~BlockStoreProvider~* & *~useBlockStore~*: Declarative Preact context wrapper and consumer hook.
- *~SettingsContext.tsx~*:
  - *~SettingsProvider~* & *~useSettings~*: Preact context provider and hook exposing reactive ~ExtensionSettings~.
  - *~useLayoutSync~*: Layer 3 reactive hook bridging settings state changes to the Layer 2 DOM adapter (~applyLayoutDeclarations~).

** dom/
:PROPERTIES:
:PATH: src/dom/
:PURPOSE: Host DOM observation, mutation scanning, conversation turn extraction, and lifecycle tracking
:FILE_TYPES: .ts, .tsx
:PRIMARY_SEAM: Browser DOM & MutationObserver API
:KEY_DEPENDENCIES: preact, src/constants.ts, src/context/BlockStoreContext.tsx, src/languages/org/
:STATUS: Active
:END:

Encapsulates all direct interactions with the host browser DOM. Isolates host-specific DOM selectors, Shadow DOM traversal, debounced scanning, and conversational data extraction behind clean, testable interfaces.

*Files & Responsibilities*:
- *~observer.ts~*:
  - *~DomObserver~*: Monitors live DOM mutations via ~MutationObserver~.
  - *Shadow DOM Scanner*: Recursively traverses open Shadow Roots to discover host chat elements.
  - *Deduplication & Debouncing*: Prevents duplicate processing of nested candidates and debounces burst streaming token mutations (80ms).
  - *Node Detachment Signals*: Detects removed DOM nodes and signals unmount cleanup to prevent memory leaks during SPA navigation.
- *~chat-extractor.ts~*:
  - *~extractChatConversation~*: Traverses the DOM tree to extract conversational turns (~user-query~ and ~model-response~).
  - *Content Preservation*: Extracts authentic code text from code blocks while stripping UI feedback buttons, retry icons, and extension overlays.
  - *Metadata Extraction*: Gathers chat titles, timestamps, and turn sequence indices for Org export.
- *~code-block.tsx~*:
  - *~CodeBlockController~*: Deep module managing code block records, single-portal mount container creation, and AST caching synchronization.
- *~InSituCodeBlock.tsx~*:
  - Code-block root component (superseded by turn-level message architecture under ADR 0008).
- *~dom.ts~*:
  - Internal DOM interfaces (~CodeBlockRecord~), element query helpers, and mounting contracts.

Houses the language identification engine, multi-language registries, AST definitions, and universal message container components.

*Files & Responsibilities*:

  - *~LanguageRegistry~*: Extensible language engine resolving language identifiers, aliases, and custom toolbar tools.
- *~definitions.ts~*:
  - Built-in database defining 37+ recognized programming and markup languages (Rust, Python, TypeScript, Org, Markdown, JSON, etc.).

  - Orchestrates collapsible summary badges, portal toolbars, and active view projection while remaining decoupled from language parsing heuristics.

**** components/
:PROPERTIES:
:PATH: src/languages/org/components/
:PURPOSE: Declarative Preact components rendering Org AST nodes into interactive DOM views
:FILE_TYPES: .tsx
:PRIMARY_SEAM: Preact JSX Components
:KEY_DEPENDENCIES: preact, src/languages/org/types/ast.ts, src/ui/folding.ts
:STATUS: Active
:END:

- *~OrgDocumentView.tsx~*: Top-level document view rendering document metadata banners (#+TITLE, #+AUTHOR), preambles, and recursive section trees.
- *~Section.tsx~*: Hierarchical headline and outline section component implementing 3-state outline fold cycling (~FOLDED~ -> ~CHILDREN~ -> ~SUBTREE~ -> ~FOLDED~), subtree copying, and nested child rendering.
- *~OrgToolbar.tsx~*: Action toolbar for code and document blocks supporting dynamic tool registration, render mode cycling, and persistent fold controls.
- *~Drawer.tsx~*: Collapsible property drawer (:PROPERTIES: ... :END:) with interactive toggle.
- *~SrcBlock.tsx~*: Syntax-highlighted source code block with header metadata (#+NAME, language tag) and one-click copy button.
- *~Table.tsx~*: Org-mode table renderer supporting header rows, cell alignment, and divider lines.
- *~List.tsx~* & *~ListItem.tsx~*: Nested lists with interactive checkbox items and real-time cookie progress recalculation.
- *~Latex.tsx~*: KaTeX mathematical formula renderer with safe error boundary fallback.
- *~InlineText.tsx~*: Renders tokenized inline runs (links, styled spans, math, progress cookies).

**** parser/
:PROPERTIES:
:PATH: src/languages/org/parser/
:PURPOSE: Org-mode lexical detection, recursive-descent parsing, and KaTeX math processing
:FILE_TYPES: .ts
:PRIMARY_SEAM: DocumentParser & Detector
:KEY_DEPENDENCIES: src/languages/org/types/ast.ts, katex
:STATUS: Active
:END:

- *~document-parser.ts~*: Universal recursive-descent parser converting Org plaintext into hierarchical AST trees, property drawers, tables, lists, and metadata directives. Also provides AST-to-text serialization (~serializeOrgSection~, ~serializeOrgDocument~).
- *~detector.ts~*: Multi-signal lexical heuristic engine (~isOrgContent~) evaluating headings, drawers, tables, directives, and math syntax to identify Org content.
- *~inline-lexer.ts~*: Inline token lexer handling Org markup (=code=, ~verbatim~, *bold*, /italic/, _underline_, +strike+), bracket links, timestamps, planning keywords, priority badges, and cookie progress fraction indicators.
- *~latex.ts~*: KaTeX math parsing pipeline converting inline ($...$, \(...\)) and display LaTeX environments into formatted HTML, with full ASCII LaTeX Greek symbol mapping (\alpha through \Omega).

** layout/
:PROPERTIES:
:PATH: src/layout/
:PURPOSE: Three-Layer Style Architecture isolating style computation from DOM mutation
:FILE_TYPES: .ts
:PRIMARY_SEAM: Three-Layer Style Architecture
:KEY_DEPENDENCIES: src/types/settings.ts
:STATUS: Active
:END:

Implements the Three-Layer Style Architecture separating pure domain logic from DOM mutation:
- *~layout-manager.ts~*:
  - *Layer 1 (Pure Core)*: ~computeLayoutStyles(settings: ExtensionSettings)~: Deterministic pure mapping function calculating CSS variables and class names from settings with zero DOM coupling. 100% testable in headless Deno.
  - *Layer 2 (I/O Adapter)*: ~applyLayoutDeclarations(target: HTMLElement, declarations)~: Minimal bridge applying style variables and classes to the target element.

** ui/
:PROPERTIES:
:PATH: src/ui/
:PURPOSE: Declarative Preact UI components, HUD overlay, dev badges, and UI interaction behaviors
:FILE_TYPES: .ts, .tsx
:PRIMARY_SEAM: Preact Components & UI Behavior Models
:KEY_DEPENDENCIES: preact, src/context/, src/storage/settings-store.ts
:STATUS: Active
:END:

Houses all user interface controls, overlays, and UI interaction models:
- *~ExtensionRoot.tsx~*: Mounts the unified extension Preact root attaching ~SettingsProvider~, ~BlockStoreProvider~, ~Hud~, and dev ~VersionOverlay~ under a single mount boundary.
- *~hud.tsx~*: Floating Heads-Up Display (HUD) control panel providing width presets, response font size stepping, Org auto-render toggle, conversation export trigger, and global outline fold cycling.
- *~VersionOverlay.tsx~*: Dev-only floating pill badge centered at top of viewport displaying dev version suffix and reload status, strictly eliminated from release builds.
- *~folding.ts~*: Pure domain UI interaction model for hierarchical outline fold cycling (~OutlineFoldState~, ~RenderMode~, ~nextLocalFoldState~, ~nextGlobalFoldState~, ~nextRenderMode~).
