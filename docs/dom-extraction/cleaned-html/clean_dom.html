The most immediate fix for the Angular comment spam is native to Chrome. Open DevTools, go to Settings, navigate to Preferences, and under the Elements heading, uncheck "Show HTML comments". This hides the endless ng-template and binding comments immediately.

For structural analysis, standard DOM inspectors fail on Angular because they show the rendering artifacts instead of the logical structure. Install the official Angular DevTools extension. It adds an Angular tab to your browser tools that reconstructs the component tree. This strips out the DOM wrapper noise and lets you inspect the logical components directly. It is much easier to map your extension logic to the component tree than the raw DOM hierarchy.

If you are building an extension, you still eventually need stable query selectors. Angular frequently uses dynamic classes and auto-generated IDs, which makes standard CSS selection brittle. To find stable attributes like custom data tags or specific structural patterns, it is often easier to pull the DOM out of the browser and filter it programmatically.

Since you are well-versed in JavaScript and Python, a solid workflow is to grab document.documentElement.outerHTML from the console and process it locally. You can use Python with BeautifulSoup or lxml to parse the document. Write a short script to traverse the tree and decompose all Comment objects. You can also write a function to unwrap tags like ng-container or generic divs that contain no attributes, flattening the hierarchy. Pretty-printing the result will give you a much cleaner map of the actual content and the stable attributes you can safely target with your extension.

If you prefer to clean the DOM live in the browser console, you can use a TreeWalker to strip comments in place. Create a TreeWalker with NodeFilter.SHOW_COMMENT, iterate through the nodes, push them to an array, and then call remove on each. You can execute a similar loop for elements, finding nodes matching generic Angular wrappers and calling replaceWith to hoist their children up. Be aware this will likely break the live Angular application state and data binding, but it is perfectly fine for static visual analysis of the structure.
