* Architecture & Core Foundation [6/6]
- [X] Pluggable Extensibility Contracts :: Standardized ~LanguageDefinition~, ~SiteAdapter~, and ~DocumentViewComponent~ contracts in ~src/core/contracts/~.
- [X] Dynamic Loading & View Dispatching :: Dynamic import loading for language document views via ~DocumentViewDispatcher~ and code splitting in the build toolchain.
- [X] Stream Settlement State Machine :: Formalized Phase A (in-flight streaming buffer) vs. Phase B (settled >300ms macro-settle) transitions with idempotent mount guards (~data-ext-processed~, ~data-ext-mounted~).
- [X] Decoupled In-Memory Caching :: 32-bit FNV-1a content-hash indexed LRU caches (~ViewStateCache~ and ~AstCache~) surviving virtual scroller recycling with 0ms instant hydration.
- [X] Scoped Logging & Telemetry Submodule :: Hierarchical scoped logging (~CoreLogger~), dynamic runlevels (~prod~, ~debug~, ~trace~), in-memory ring buffer, Preact lifecycle profiling hooks, and global console API (~window.__AI_CHAT_UI__~). See [[file:../.scratch/logging/spec.org][Logging Spec]].
- [X] Tailwind CSS v4 In-Process Pipeline & Shadow DOM :: Compiled in-process at build time and injected as a singleton ~adoptedStyleSheets~ constant, eliminating runtime network overhead and memory duplication across Shadow Roots per [[file:adr/0002-tailwind-v4-shadow-dom.org][ADR 0002]]. See [[file:../.scratch/tailwind-integration/spec.org][Tailwind Integration Spec]].

* Rendering Capabilities & Languages [8/13]

- [X] Headless Org-Mode AST Engine :: Canonical Emacs ~org-element.el~ specification AST, O(N) streaming block parser with headline stack hierarchy, delimiter disambiguation, affiliated keywords (~#+NAME:~, ~#+CAPTION:~), tables with rules/alignment, and rich inline objects. See [[file:../.scratch/org-ast/spec.org][Org AST Spec]].
- [X] Language Registry & AST Settlement Pipeline :: Centralized ~LanguageRegistry~ with language-agnostic ~settleContent~ coordinating pre-parsing and AST caching during turn settlement.
- [X] In-Situ Preact Org Document View :: Rich declarative Preact view component (~OrgDocumentView~) rendering collapsible headline sections, TODO state badges, priority chips, tags, property drawers, and description lists. See [[file:../.scratch/org-document-view/spec.org][Org Document View Spec]].
- [X] Canonical 3-State Outline Visibility Cycling :: Full Emacs Org-mode outline cycling across all headline levels: ~folded~ (\blacktriangleright + ...), ~children~ (\rhd + ...), and ~subtree~ (\triangledown) with descendant state pruning and full-card click targets.
- [X] Offline KaTeX Mathematical Typography :: Bundled 100% offline KaTeX WOFF2 fonts and CSS rendering inline math, display equations, and ASCII LaTeX Greek entities into declarative JSX without ~innerHTML~ per [[file:adr/0001-katex-math-pipeline.org][ADR 0001]].
- [X] Inline Image & Dynamic Attachment Previews :: In-situ rendering of embedded ~[[file:...]]~ and ~[[https://...]]~ image links with interactive zoom modal overlay.
- [X] Org Document View Polish & Scoped Subtree Actions :: Compact boxed headings, row-click folding, inline chevron alignment, display LaTeX centered block rendering, and headline-scoped subtree copying via ~serializeOrgSubtree~.
- [ ] Universal Syntax Highlighting Module :: Decoupled syntax highlighting engine in ~src/views/common/CodeHighlighter.tsx~ with modular, code-split grammars (Python, TypeScript, Rust, Bash, SQL, JSON) mapped to Tailwind v4 theme tokens without external network requests. See [[file:../.scratch/syntax-highlighting/spec.org][Syntax Highlighting Spec]] and [[file:../.scratch/syntax-highlighting/issues/01-universal-syntax-highlighting-module.org][Issue 01]].
- [ ] Custom Org Themes & Syntax Presets :: User-selectable color schemes (Org Modern, Doom One, Solarized, Gruvbox) for rendered headlines and code blocks.
- [ ] LaTeX Math Pipeline Delimiter & Greek Entity Refinement :: Refine tokenizer sequencing to prevent raw Greek entity replacement from corrupting complex LaTeX math environments prior to KaTeX execution. See [[file:potential-features.org][potential-features.org]].
- [ ] GitHub Flavored Markdown (GFM) Document View & AST Engine :: Complete feature parity with the Org engine: pure headless AST parser, outline visibility cycling (folded/children/subtree), H_0 heading parity, GitHub alerts ([!NOTE], [!TIP], etc.), GFM pipe tables with alignment, interactive task lists, KaTeX math, scoped subtree copying, and full-message GFM serialization. See [[file:../.scratch/markdown-document-view/spec.org][GFM Document View Spec]].
- [ ] Additional DocumentViews :: Pluggable DocumentViews for JSON tree structure and Mermaid diagram rendering.
