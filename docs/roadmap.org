#+TITLE: AI Chat UI Improvements — Planned Features & Roadmap
#+DATE: 2026-09-08
#+OPTIONS: toc:2 num:nil

* Architecture & Core Foundation [5/5]
- [X] Pluggable Extensibility Contracts :: Standardized ~LanguageDefinition~, ~SiteAdapter~, and ~DocumentViewComponent~ contracts in ~src/core/contracts/~.
- [X] Dynamic Loading & View Dispatching :: Dynamic import loading for language document views via ~DocumentViewDispatcher~ and code splitting in build toolchain.
- [X] Stream Settlement State Machine :: Formalized Phase A (in-flight streaming buffer) vs. Phase B (settled >300ms macro-settle) transitions with idempotent mount guards (~data-ext-processed~, ~data-ext-mounted~).
- [X] Decoupled In-Memory Caching :: 32-bit FNV-1a content-hash indexed LRU caches (~ViewStateCache~ and ~AstCache~) surviving virtual scroller recycling with 0ms instant hydration.
- [X] Scoped Logging & Telemetry Submodule :: Hierarchical scoped logging (~CoreLogger~), dynamic runlevels (~prod~, ~debug~, ~trace~), in-memory ring buffer, Preact lifecycle profiling hooks, and global console API (~window.__AI_CHAT_UI__~).

* Testing and Toolchain Improvements [3/3]
- [X] Multi-Target Bundle Script :: Modular ~build.ts~ supporting dev builds (~dist/dev/~ via ~deno task build:dev~) and production releases, manifest generation, dynamic bootloader, and code splitting.
- [X] Chat-Independent Mock Testing :: Static HTML chat fixtures and DOM-independent tests using ~@b-fuze/deno-dom~ for testing adapters and views without browser runtime overhead.
- [X] Headless Domain Unit Testing :: Deterministic unit test suite testing pure AST parsing, inline tokenizing, content hashing, view state, and AST caching with zero DOM dependencies (~deno task test~).
- [ ] Consider Updating Tests to a Dedicated Preact Unit Test Library :: There are dedicated preact libraries facilitating unit tests, and we should consider updating our tests to use one. (https://github.com/developit/preact-jsx-chai, https://github.com/bruderstein/unexpected-preact)

* Host Interface Extensions [4/5]
- [X] Gemini Adapter :: Full Gemini scraper (~GeminiScraper~), DOM observer (~GeminiDOMObserver~), and shadow root injector (~GeminiInjector~) matching Gemini's custom element tree.
- [X] Host Theme Authority :: Implemented ~theme~ and ~onThemeChange~ contracts on ~src/chat/gemini/theme.ts~ to observe host light/dark mode and synchronize Shadow Root themes.
- [X] Host Auto-Discovery Registry :: Centralized ~ChatAdapterRegistry~ with eager and lazy resolution based on URL hostname and DOM fingerprints.
- [X] Non-Destructive Host Isolation :: CSS hiding (~display: none~) and open Shadow Roots isolating extension styles while preserving native ~code[data-test-id='code-content']~ for host copy parity.
- [ ] Multi-Platform Chat Adapters :: Extend adapters to support ChatGPT, Claude, and DuckDuckGo AI.

* Rendering Capabilities & Languages [7/9]
- [X] Universal In-Situ Code Block Container :: Universal ~InSituCodeBlockContainer~ with custom toolbar, language badge, folding toggle, view toggling, and copy parity button.
- [X] Headless Org-Mode AST Engine :: Canonical Emacs ~org-element.el~ specification AST, O(N) streaming block parser with headline stack hierarchy, delimiter disambiguation, affiliated keywords (~#+NAME:~, ~#+CAPTION:~), tables with rules/alignment, and rich inline objects.
- [X] Language Registry & AST Settlement Pipeline :: Centralized ~LanguageRegistry~ with language-agnostic ~settleContent~ coordinating pre-parsing and AST caching during turn settlement.
- [X] In-Situ Preact Org Document View :: Rich declarative Preact view component (~OrgDocumentView~) rendering collapsible headline sections, TODO state badges, priority chips, tags, property drawers, and description lists.
- [X] LaTeX / KaTeX Math Pipeline :: Dynamic KaTeX math fragment rendering ($...$, \(...\)) and ASCII LaTeX Greek entity replacement per ADR 0001.
- [X] Org Document View Polish & Scoped Actions :: Stage 4: Compact boxed headings, row-click folding, inline chevron alignment, display LaTeX ($$...$$, \[...\]) centered block rendering, headline-scoped subtree copying, and host non-Org block bypass.
- [ ] Custom Org Themes & Syntax Presets :: User-selectable color schemes (Org Modern, Doom One, Solarized, Gruvbox) for rendered headlines and code blocks.
- [X] Inline Image and Dynamic Attachment Previews :: In-situ rendering of embedded ~[[file:...]]~ and ~[[https://...]]~ image links with zoom overlay.
- [ ] Additional DocumentViews :: Pluggable DocumentViews for JSON, Mermaid diagrams, and Markdown.
- [ ] Chat width control :: The chats need to be wider, and there needs to be user control for how wide (in the floating HUD, see [[*HUD & User Controls][HUD & User Controls]])

* HUD & User Controls [0/4]
- [ ] Moveable HUD :: Click and drag the HUD box around the chat column.
- [ ] Universal HUD Integration :: Compute default position for HUD seamlessly across supported host platforms to avoid visual collision with host toolbars.
- [ ] Customizable Hotkeys & Keybindings :: User-configurable shortcut bindings for HUD toggle, folding, font sizing, and export actions.
- [ ] Previous Versions UI :: Read-only "Previous Versions" inspection panel/button allowing users to review and restore historical user query and model response versions from the tree store.

* Chat Storage, History & Export [0/5]
- [ ] Tree-Structured Conversation Store :: Append completed streaming turns to persistent ~browser.storage.local~ in a branching tree model to preserve query edits and regenerated responses.
- [ ] Branch Navigation & Lineage Resolution :: Map linear chat views to historical branching paths, especially across hosts without native branching support.
- [ ] Multi-Format & Scoped Subtree Copying :: Provide copy actions for specific headlines, functions, or subtrees, alongside multi-format copy ("Copy as Raw Org", "Copy as Markdown").
- [ ] Subtree & Turn Selection Export :: Allow selective downloading of individual turn subtrees or marked sections into ~.org~ files.
- [ ] Complete Conversation Exporter :: Markdown-to-Org AST converter generating clean, annotated Org documents with metadata drawers.
