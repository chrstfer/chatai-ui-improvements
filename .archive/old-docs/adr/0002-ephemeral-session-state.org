#+TITLE: ADR 0002: Ephemeral In-Memory Session State
#+DATE: 2026-09-03

:PROPERTIES:
:STATUS: Accepted
:END:

* Status
Accepted

* Context
Browser extensions often persist UI toggles (e.g. widescreen mode, auto-rendering) across sessions using ~chrome.storage.local~ or ~chrome.storage.sync~. However, for a chat workspace tool, persistent state can lead to unexpected layout shifts, accidental auto-rendering of non-Org code on fresh sessions, and synchronization complexity across multiple tabs.

* Decision
All extension settings and interactive states are strictly *ephemeral in-memory session states* per tab:
- Every page load and full browser reload resets all settings to their default values:
  - ~fullWidth = false~ (standard Gemini layout)
  - ~autoRenderOrg = false~ (manual per-block rendering by default)
  - ~widthPercent = 86%~ (ready when ~fullWidth~ is toggled on)
  - Floating HUD anchored at ~bottom: 5.5em; right: 24px;~ to clear prompt inputs.
- No asynchronous ~chrome.storage~ calls or cross-tab synchronization layers are required.

* Consequences
** Positive
- Zero storage I/O latency or serialization bugs.
- Clean, predictable baseline behavior on every visit to Gemini.
- Zero state pollution or stale configuration flags.

** Negative
- Users must press ~Alt+W~ or click the HUD preset once per session if they desire widescreen on a fresh tab.
